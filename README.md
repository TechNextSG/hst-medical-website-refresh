# HST Medical website refresh v2.2

**For:** McGallen & Bolden · **From:** TechNext · **Date:** 12 October 2026

This package restyles hstmedical.com within its existing classic GeneratePress + WP EasyCart setup.
It is 2 GeneratePress settings files, 1 CSS file and the graphics. It adds no scripts and makes no template or plugin changes.

- **Website mockup - the whole hstmedical.com (532 pages) with the new design:** https://technextsg.github.io/hst-medical-website-refresh/mockup/
- **Supporting documents (view online):** https://technextsg.github.io/hst-medical-website-refresh/
- **Install guide:** [00_Install-Guide.md](00_Install-Guide.md) (about 20 minutes)
- **Download everything as one zip:** [download/HST-Medical_Website-Refresh_v2.2_2026-10-12.zip](download/HST-Medical_Website-Refresh_v2.2_2026-10-12.zip)

| File | What it is |
|---|---|
| `hst-gp-1-global-colors.json` | GeneratePress colour palette (import) |
| `hst-gp-2-typography.json` | GeneratePress type scale (import) |
| `hst-refresh.min.css` | Paste into Appearance > Customize > Additional CSS |
| `hst-refresh.css` | Same CSS, readable, for future edits |
| `graphics/` | Home-page panels, offer banner (JPG + WebP), trimmed logo |

Back up first (GeneratePress Import / Export > Export, plus the current Additional CSS). Full steps are in the install guide.
